## User model

Task-it v1 is a personal single-user task manager.

The application does not include:
- user registration
- authentication
- authorization
- roles
- multi-user support

All tasks implicitly belong to the single user of the application.

## V1 scope

Task-it v1 allows the user to:

- create a task
- view all tasks
- view task details
- update a task
- delete a task
- assign a priority
- set an optional due date
- change the task status
- filter tasks
- sort tasks

## Out of scope for v1

The following features are intentionally excluded from the first version of Task-it:

- user registration
- authentication
- authorization
- multiple users
- shared tasks
- teams
- comments
- attachments
- notifications
- reminders
- recurring tasks
- subtasks
- tags
- categories
- real-time synchronization
- WebSockets
- mobile applications
- calendar integrations
- external service integrations
- audit log
- task history/versioning
- soft deletion
- custom priorities
- custom statuses
- role-based access control
- multi-tenancy
- caching
- message brokers
- event-driven architecture
- CQRS
- event sourcing
- microservices
- Kubernetes
